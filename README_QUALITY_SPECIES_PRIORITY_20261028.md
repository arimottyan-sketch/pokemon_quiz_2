# 2026-10-28 ポケモン別知識優先への改訂

- 既存801件の原文レコードを変更せず、公式から取得した6件の原文レコードを追加：合計807件。
- 280枠全て四択出題可能。独立した原文を2件使用するコード上の枠数：279/280。No.504は元図鑑説明の段階開示で代替（2件の独立情報を揃えたとは扱わない）。
- 意味の独立性という意味では、No.515ヒヤップとNo.602シビシラスの新資料は旧図鑑と主題が重複するため、さらに改善要。技の独占使用が未確認の No.1021タケルライコは技ではなく公式図鑑の『オカルト雑誌』と『体毛の雷』を採用。
- 低品質と特定した「汎用技の効果」を語るレコード（ミネズミ『おさきにどうぞ』、ヤナップ『アクロバット』、バオップ『はじけるほのお』、ヒヤップ『ねっとう』、シャリタツのヘイラッシャ『いっちょうあがり』）は、原文を削除せず全クイズモードの出題対象から除外。加えてタケルライコの『じんらい』の効果説明は、公式の当該ページだけでは『そのポケモンだけが使える』と確認できないため出題から外す。同じ身体的特徴を繰り返す紹介文も除外し、独立した二つの公式図鑑説明を採用。
- シビシラスの『Pokémon GO』イベント告知も出題対象から除外。
- 公式ソースを直接照合した今回の追加分は6件。以前の公式データ801件全件の再照合は完了していない。
- 変更された第1ヒントは7枠（ヤナップ・バオップ・ヒヤップ・シビシラス・シャリタツ・ミネズミ・タケルライコ）。公式原文の新規追加は6件。
- 2011年アニメのバオップ＆ヤナップ兄弟バトルは資料として残し、出題優先は2025年カードの300度以上の生態へ。
- 技を題材にする場合は、そのポケモンだけに固有と公式資料で裏付けられる場合を例外的に許容し、単なるわざ紹介は採用しない。技の使われ方を通じた**具体的な作中での活躍**は別途評価する。
- 画像の実ブラウザ操作・全既存801件の原文照合・すべてのフォームの公式特性網羅は未検証。
