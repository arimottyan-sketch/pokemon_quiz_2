# 新モード：だんだんヒント（このポケモンは誰？）

既存のモードや690件の固定データを変更せず、出題形式を一つ追加しています。

## 使い方

Streamlit の「クイズ」画面で「問題形式」→「だんだんヒント（このポケモンは誰？）」を選択。「クイズを始める」を押します。最初は少し難しい公式情報だけが表示され、四択でいつでも解答できます。「次のヒントを表示」を押すと段階的に開示します。

1. 公式HP・映画・アニメなどの図鑑外の個別情報を優先（なければ別の図鑑説明）
2. 追加のゲーム内図鑑等の公式文章
3. 特性（株式会社ポケモンの公式ポケモンずかんに記載された情報）
4. タイプ（同上）
5. シルエット（既存の姿画像URLをCSSで黒く表示）

最初に当てると5点、最後のヒントを見たあとなら1点。不正解は0点。公式サイトの一時的な取得失敗でヒントが欠落した場合、その段階では減点しません。正解後は出典・原文とカラーの姿を表示します。

**重要な制約**：公式文章2件が独立して存在し、図鑑外情報は出題承認された対象に限っています。既存の情報だけでは全280枠を対象にできません。また特性・タイプは本アプリの基礎データに含まれていないため、公式サイトからそのポケモンのプロフィールを閲覧時に読み込みます（少数の実照合済み値のみ同梱）。通信できない・公式ページのHTML構造が変更されたときは、分からない情報を推測して表示せず、取得不可とし、そのヒントは減点対象から外します。

シルエット用の既存PokeAPI公式アート画像ミラーは通信が必要です。PokeAPI自体から特性・タイプなどのゲーム内事実は取得しません。

## インストール

`pip install -r requirements.txt` → `streamlit run app.py`。Github / Streamlit Community Cloud は既存構成と同様です。追加ファイル `progressive_quiz.py` と依存 `beautifulsoup4` が必要です。公式の固定引用 `data/official_quotes.json` は改変していません。

## 確認範囲

`python -m unittest discover -s tests -v` で検証できます。クイズ候補全件の実際の公式ページへのHTTP取得はこのビルド環境の通信制約により実行できず、構文パーサは公式ページ掲載構造に近い模擬HTMLを使った単体テストです。ブラウザー表示／シルエットのネットワーク取得も未検証です。
