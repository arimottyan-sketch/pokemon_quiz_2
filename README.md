# イッシュ・パルデア｜クイズとポケモン情報

## GitHub / Streamlit 公開手順

1. ZIPを解凍して、**中のファイルと `data` フォルダ**をGitHubリポジトリの最上位へアップロードしてください。ZIP自体を1ファイルとしてアップロードしても実行できません。
2. Streamlit Community CloudのMain file pathは `app.py` を指定してください。既存のアプリならGitHubにコミットすると更新されます。
3. 画面の「クイズ」「ポケモン情報」「使い方」を切り替えて利用してください。

## ファイル構成

- `app.py`：アプリ本体（出題・検索・復習のロジックを内蔵）
- `theme.css`：配色とレイアウトの調整（隠しフォルダなし）
- `requirements.txt`：必要ライブラリ
- `data/official_quotes.json`：公式掲載文データ（前版から変更なし）
- `self_check.py`：Streamlitがない環境での簡易動作検査

このZIPには名前が `.` で始まるファイル・フォルダは含まれていません。

## 旧ファイルの整理

以前の版で追加した古いCSS・補助Pythonファイルは新しいアプリでは参照しません。不要なら公開リポジトリから削除してください。`README.md` と `app.py` は必ず最新版で置き換えてください。

## 動作確認範囲

- 既存の公式掲載文458件は変更していません。前版とのSHA-256ハッシュを比較してください。
- クイズ問題生成、検索、モード選択、テキスト表示についてテストします。
- Streamlit本体を使った公開URLでのブラウザ起動はこの環境では未確認です。

## 配色

`theme.css` の先頭にある `--quiz-accent`、`--quiz-action` などを編集すると色を変更できます。
Streamlitテーマ全体を完全に置き換えるものではなく、CSSで画面の色を調整します。
