# ポケモンスタッフ学習クイズ — ImportError対策版

## 導入
ZIPを解凍し、以下のファイルをGitHubリポジトリの直下に配置してください。

- `app.py`（クイズエンジン・学習ロジックをすべて内蔵）
- `requirements.txt`
- `staff_theme.css`（配色）
- `data/official_quotes.json`（公式掲載文の既存データをそのまま保存）

**注意：リポジトリ直下に `app.py` を置くこと。** ZIPをそのまま1ファイルとしてアップロードしないでください。
Streamlit Community CloudのMain file pathは`app.py`です。

### 今回の不具合対策
前版ではapp.pyがquiz_engine.pyとstaff_learning.pyを読み込み、GitHubに古いファイルが残るとImportErrorになる可能性がありました。これらの処理をapp.pyへ内蔵したので、既存の同名ファイルが残っていてもアプリの起動時には参照しません。

不要となった古い`quiz_engine.py`、`staff_learning.py`はGitHubから削除しても構いません。
このZIPには先頭が`.`のファイル・フォルダは含まれません。

### 配色
配色は `staff_theme.css` に保存しています。変更する場合はファイル先頭のCSS変数を変更してください。Streamlitのウィジェットすべてを公式テーマと完全に同等に設定する方式ではなく、CSSから外観をカスタマイズする方式です。

### 検証範囲
- エンジン・学習ロジック・データの読み込み、100件以上の問題生成、静的構文検査をローカルで検証。
- Streamlit本体がこの実行環境にないため、実Streamlitによるブラウザ起動試験は未実施です。
- 収録済み公式文章データは元ZIPからバイト単位で変更していません。既存文章全件の公式サイト原文照合をやり直したものではありません。

### エラー時のログ
アプリ右下の`Manage app`からログを開き、末尾の例外全文を参照してください。スクリーンショット上では原文が伏せられている場合があります。
