# ポケモンクイズ（文脈・選択肢修正版）

前回の631件の元データ本文・URL・帰属は変更していません。直前の作業フォルダーに保存されていた7件の調査レコードを含む、計638件が同梱されています。これは638件全てを今回新たに一次情報で逐字照合した、という意味ではありません。

## GitHub / Streamlit への設置
このZIPを展開し、`app.py`、`quiz_engine.py`、`theme.css`、`requirements.txt`、`data/` を同じ階層でGitHubにアップロードしてください。Streamlit Community Cloudの Main file path を `app.py` にします。ローカル環境では `pip install -r requirements.txt` に続いて `streamlit run app.py` を実行します。

## 今回の改修
- 見出しは「ポケモンクイズ」を維持。選択肢や設問には説明に不要な「適用範囲」注釈を表示しません。
- アニメ・ゲーム固有の出来事は、短い前後文を補って作品名、誰が何をしたか、確定情報か作中の説かを明示します。
- **元の引用 `text` を書き換えず**、必要十分な説明は `question_text` に別置き。解答後は原文抜粋と公式出典URLを確認できます。
- 例：アギルダー、アイアント、メグロコ、パモット、テツノワダチ、ゲノセクトなど。
- 技・特性の説明が選択肢だけに残らず、対象ポケモンの情報として成立するよう主語・作品を補いました。
- 短い見出し・途切れた文・曖昧な登場場面は保留、段落を確認できた場合のみクイズ用に補完。
- 選択肢A～Dと正しい内容を誤答時に表示する従来仕様を保持。
- **軽量表示**チェックボックス追加：文章→名前の四択では選択肢の画像4枚を省略。画像が必要な問題は画像を表示します。
- 前段階の原資料631件 + 作業中の調査7件 = 計638件のうち、図鑑説明405件、図鑑外233件。図鑑外で出題候補となるのは117件（81枠）。116件は残したまま保留・除外。
- `data/non_dex_quality_current.csv`：各図鑑外情報の現在の採否、元引用、表示文章、出典、注記。`data/question_context_changes.csv`：今回の編集履歴。
