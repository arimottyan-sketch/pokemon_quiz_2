# イッシュ・パルデア｜スタッフ自主学習ポケモンクイズ

ポケモンセンターで来店された方にポケモンの名前や特徴を伝える場面を想定した、**非公式の自主学習アプリ**です。株式会社ポケモン・ポケモンセンターの公式運営または認定研修ではありません。

## 何ができるか

- **バランスよく**：姿→名前、図鑑説明→名前、姿→説明、公式トリビア→名前を組み合わせて出題
- **姿を見て名前を選ぶ**：店頭の商品・イラストの見分け方を練習
- **図鑑説明から名前を選ぶ**：2×2の**画像付き**選択肢
- **姿から図鑑説明を選ぶ**：生態・特徴の紐付けを練習
- **公式トリビアから名前を選ぶ**：図鑑以外の公式HP・アニメ公式紹介・ポケモンセンター公式グッズ紹介・別作品の図鑑補足を利用し、カード・大会情報は出題に使わない
- **名前入力（上級）**：選択肢なしで名前を書く
- **苦手だけ復習／★あとで復習**：誤答したポケモンの一覧や登録したポケモンを集中的に復習
- **ポケモンを調べる**：名前・全国図鑑番号・本文キーワードで検索し、公式文章と出典を確認
- **履歴CSV保存**：個人名を記録せず、当該ブラウザセッション中の解答履歴をダウンロード

地方は「イッシュ」「パルデア」「両方」から選択、問題数は5・10・20・30・全問。イッシュ156種類、パルデア120種類＋パルデアのすがた4種類の合計**280種類・すがた**に対応します。

## 公開方法（GitHub + Streamlit Community Cloud）

1. ZIPを**解凍**する。
2. **ZIPの中身**（`app.py`、`staff_learning.py`、`quiz_engine.py`、`requirements.txt`、`data/`、`.streamlit/` など）をGitHubリポジトリ直下にアップロードする。以前の同名ファイルは置き換える。ZIPを丸ごと1ファイルとしてアップロードするだけでは動かない。
3. [Streamlit Community Cloud](https://share.streamlit.io/) から `Create app` → GitHubリポジトリを選択する。
4. `Branch: main`（実際のブランチ名に合わせる）、`Main file path: app.py` としてデプロイする。
5. アプリが表示され、学習開始・問題回答・復習・検索が動くか公開環境でも確認する。

ローカルでの実行：

```bash
pip install -r requirements.txt
streamlit run app.py
```

オフラインのユニットテスト：

```bash
python -m unittest discover -s tests -v
```

`.github/workflows/check.yml` でpush時にコードの構文とテストもチェックします。

## データの扱い

- **既存の公式文章を変更していません。** 旧版の417件、前回追加17件（合計434件）は各レコードの内容を維持し、新たな抜粋12件を追記しました。更新後446件です。
- 問題画面では正解の名前が読めないように表示だけを伏せます。ファイル内の原文は変えません。回答後は全文と掲載元URLを表示します。
- 過去からの既存417件すべての公式掲載ページへの逐語的な再照合を**今回実施したわけではありません**。既存の出典管理状態は引き継いでいます。
- 通常のポケモン画像はPokeAPIの公開スプライト画像URL、リージョンフォーム画像はPokeAPIから姿別の画像を取得しています。PokeAPIは公式情報源の本文ではありません。画像を取得できなければ、異なる姿で代用せず欠落を案内します。
- 画像と外部ソースのリンク表示にはインターネット接続が必要です。公式テキストと四択の生成は固定データから行い、出題時に自動スクレイピングしません。
- 本アプリは店舗の在庫、最新キャンペーン、商品価格、営業時間を提供しません。正確な店舗案内は公式の店舗告知を参照してください。
- 復習データ・解答履歴は**セッション内のみ**で、閉じると失われます。ダウンロードしたCSVを再アップロードして復元する機能はありません。

## ファイル構成

| ファイル | 用途 |
|---|---|
| `app.py` | Streamlit画面・選択肢の表示・復習UI |
| `staff_learning.py` | 出題計画・地方横断・復習対象・CSV出力（事実を書き換えない） |
| `quiz_engine.py` | 出典URLなどの形式チェック・問題の生成・伏字処理 |

| `data/pokedex.json` | 旧形式との互換性維持用 |
| `data/paldea_forms_sources.json` | すがた違いの出典管理 |
| `tests/` | ロジックと描画呼び出しの自動テスト |
| `.streamlit/config.toml` | 配色・見た目の設定 |
| `.github/workflows/check.yml` | GitHubでのプッシュ時テスト |
