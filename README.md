# ポケモン四択クイズ（公式原文補足100件追加）

本パッケージは **276匹、収録文章409件**（追加前309件＋今回100件）を含みます。

## GitHub / Streamlit Community Cloud で使う
1. ZIPを解凍し、**ZIP直下のファイルとフォルダを全て** GitHub リポジトリのルートへ配置してください。ZIPそのものをGitHubに置くのではありません。
2. Streamlit Community Cloud でリポジトリを選び、メインファイルに `app.py` を指定してください。
3. `requirements.txt` の依存パッケージがインストールされます。画面表示にはネットワークが必要です（画像・名前の取得にPokeAPIを使用）。

## 補足文章について
- 今回の100件は、ポケモン公式ずかんとゲーム公式HP、テレビ東京アニメ公式ページに実際に掲載された**原文（抜粋）**です。要約・改変はしていません。原文の全角スペースなども保持しています。
- 別作品の説明文を選び、同一文字列の重複5件は追加しませんでした。100件の全記録は `ADDED_100_OFFICIAL_VERBATIM.csv`、除外は `EXCLUDED_EXISTING_DUPLICATES.csv`。
- 追加分は `kind=ゲーム内図鑑の補足` で保存し、正答後の「その他の公式情報（補足）」に表示されます。元の四択に使う説明文は変更しません。
- 今回の内訳は公式ゲーム図鑑97件、ゲーム公式HP2件、テレビ東京アニメ公式あらすじ1件です。公式Xから今回新たに取得できた投稿はありません。古いゲームの文章（ポケモンＹ、ソード、シールド等）も含まれます。
- 既存309件の再検証を今回実施したという意味ではありません。オンライン上でのStreamlitデプロイと表示はこの環境では未検証です。
