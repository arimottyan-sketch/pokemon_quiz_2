# ポケモン公式文章クイズ ― イッシュ・パルデア（再構築版）

## 使い方

ZIPの中身をそのままGitHubのStreamlit用リポジトリに置いてください。`data` と `tests` はフォルダー階層を維持します。
Streamlit Community Cloud でリポジトリとブランチを選び、Main file pathに `app.py` を指定してください。
ローカルでは `pip install -r requirements.txt` のあと `streamlit run app.py` で起動します。

## この版で改善したこと

* 対象はイッシュ地方156種類、パルデア地方120種類、指定リージョンフォーム4枠＝280枠。
* 旧データ `data/source_original_631.json` の**本文・出典・帰属**は変更していません。登録総数631件（図鑑405件、図鑑外226件）。
* 図鑑外226件をレコード単位で見直し、**163件・110枠**を「出題候補」として登録。以前の28件に限定したホワイトリストを廃止。
* **図鑑外ミックス**の「全問」は、110種類ではなく**163件の異なる資料情報**をすべて1問ずつ出題します。イッシュ72件、パルデア91件。
* 図鑑外の「公式情報→名前」「名前・姿→公式情報」、図鑑問題、従来のミックス、名前入力、復習、問題数設定を保持。
* 11件のメガシンカ後など特定の姿に関する記述は、通常の姿のイラストで誤認させないように「公式情報→名前」の**文字選択肢**に限定します。
* 公式文章は原文の保存欄では変更しません。表示時だけ正解ポケモン名の伏字を適用します。作品個体・作中の伝承である場合は、クイズ上に適用範囲を表示します。
* 過去に誤ってハバタクカミに割り当てられたテツノブジンの記述は出題しません。資料閲覧画面でも誤帰属記録を表示しません。

## 調査・採用の透明性

`data/non_dex_full_audit.csv` に図鑑外**226件すべて**の原文、対象、公式URL、採用可否、理由を記録しました。
**出題保留63件は元データから削除していません。** うち11件は、元の編集済み文章を公式掲載文と逐字突合していないための保留です。それ以外には情報量が不足する断片、過去に不適切と判定された情報、対象誤帰属などがあります。

採用163件についても、**今般すべての公式ページを新たに逐字照合したとの意味ではありません**。過去の収集・出典確認記録および公式URLに基づく候補であり、本版では公式文の文字列保存性・出題ID・選択肢重複・伏字を自動テストしています。正式運用前の目視校正は引き続き推奨します。既存の図鑑405件の逐字再照合も今回完了していません。

`data/source_record_sha256.json` には全631レコードのテキストのハッシュが入っています。比較用の元資料は `data/source_original_631.json` です。

## チェック方法

```
python -m unittest discover -s tests -v
```

6項目の自動テスト：対象と631原資料本文の不変性、監査表・採用数、図鑑外の全163件が別問題になるか、4択のID・文章選択肢の重複、従来ミックス・復習、除外内容の再混入防止。

**実画面の起動確認について**：本環境にはStreamlitがインストールされておらず、実際のWeb画面での動作確認はできていません。Pythonの構文検査・ロジックテストは実施しました。

**画像**：PokeAPIが返す公式アートワーク表示を利用します。PokeAPIによる素材表示と、問題内容の公式一次出典は区別します。画像URLが取得できない場合は通常姿で代用しません。
