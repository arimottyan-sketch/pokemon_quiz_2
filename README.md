# ポケモンクイズ

## 使い方

ZIPの中身をそのままGitHubのStreamlit用リポジトリに置いてください。`data` と `tests` はフォルダー階層を維持します。
Streamlit Community Cloud でリポジトリとブランチを選び、Main file pathに `app.py` を指定してください。
ローカルでは `pip install -r requirements.txt` のあと `streamlit run app.py` で起動します。

## 今回の修正（選択肢・文章の品質）

- **画面タイトル「ポケモンクイズ」に戻しました。** 作品・伝承の適用範囲についての冗長な注意書きを問題画面から撤去しました。
- 四択の誤答時に、固定の「正解は（ポケモン名）」ではなく、**正しい選択肢の記号 A/B/C/D と、実際の選択肢内容**を表示します。
- 誤答選択肢についても回答した記号を表示します。
- ゲーム内図鑑は原文不変。図鑑外は `question_text` が設定された記録だけ、元の `text` とは**別の問題表示文**を使います。出典リンクと原文は解答後に残ります。
- 公式の前後文を照合し、ワッカネズミ、アーケン、タケルライコ、ウネルミナモ、テツノイサハ、ラウドボーン等の問題を修正しました。
- ミミズズの小説の場面など、**そのポケモンの識別につながらないものや、単独では不完全な断片**を除外しました。`data/question_quality_audit.csv` に理由があります。
- 図鑑外226件中、出題候補は**127件**。全件の正答一意性や公式全文との再照合を完了したという意味ではありません。
- 地方・問題形式・全問出題、画像、復習、原文・出典の表示、過去の631件の資料保持は維持しました。

## 調査・採用の透明性

`data/non_dex_full_audit.csv` と `data/question_quality_audit.csv` に図鑑外226件すべての原文、表示文、対象、出典、現在の採用状況と理由を記録しています。
旧判定は `data/non_dex_full_audit_previous_snapshot.csv` に保管しました。

**図鑑外127件（87種類）が出題候補、99件は出題対象外または保留です。** 未収録の情報は削除していません。出題候補127件は全件の意味的な正解一意性まで人手検証したとの意味ではありません。

前回原資料631件の `text`、帰属、URLは変更していません。図鑑外の問題表示用に公式HPの段落と照合した `question_text` を別フィールドへ追加しています。過去から収録済みの405件の図鑑原文について、今回一字一句の再照合は行っていません。

`data/source_record_sha256.json` に元資料のハッシュがあり、比較用の元データは `data/source_original_631.json` です。

## チェック方法

```
python -m unittest discover -s tests -v
```

10項目の自動テスト：対象と631原資料本文の不変性、監査表・採用数、図鑑外の全127件が別問題になるか、4択のID・文章選択肢の重複、従来ミックス・復習、除外内容の再混入防止。

**実画面の起動確認について**：本環境にはStreamlitがインストールされておらず、実際のWeb画面での動作確認はできていません。Pythonの構文検査・ロジックテストは実施しました。

**画像**：PokeAPIが返す公式アートワーク表示を利用します。PokeAPIによる素材表示と、問題内容の公式一次出典は区別します。画像URLが取得できない場合は通常姿で代用しません。

## 検証

`python -m unittest discover -s tests -v` の実行結果は配布ZIP同梱のテストで確認できます。Streamlit本体がこの環境になく、画面をブラウザで操作しての検証は行っていません。
