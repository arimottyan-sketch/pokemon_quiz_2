# イッシュ・パルデア｜クイズとポケモン情報

イッシュ地方・パルデア地方のポケモンを対象にした四択クイズと公式掲載文の検索アプリです。

## GitHub → Streamlitで公開

1. このZIPを解凍し、**中のファイルと `data` フォルダ**をGitHubリポジトリの一番上（ルート）へアップロードしてください。ZIP自体をアップロードしても起動しません。
2. 既存の `app.py`、`data/official_quotes.json`、`requirements.txt`、`theme.css` は新しいものに置き換えてください。
3. Streamlit Community CloudのMain file pathには `app.py` を指定します。既に公開している場合はGitHubの変更が反映されるのを確認してください。

このZIPに名前が `.` で始まるファイルやフォルダはありません。配色は `theme.css` に保持しています。

## 主な機能

- 「公式情報 → 名前」：公式の文章を読んで、画像付きの四択から名前を選ぶ。
- **新**「名前・姿 → 公式情報」：ポケモンの名前と画像を見て、公式情報の文章を四択で選ぶ。
- 「姿 → 図鑑説明」「図鑑説明 → 名前」「姿 → 名前」「名前入力」、およびミックス。
- **新** 近いテーマ（ほのお・でんき・水・かわいい雰囲気など）や文章の類似性を利用し、紛らわしい誤答を優先する。ポケモン同士のテーマ分類は表示せず、公式文章を編集しません。関連候補が十分にない場合は、文章の類似性などによって選びます。
- **新** 回答後にも「ここまでで終了」を表示。解答済みの点数を保持して結果画面に移動します。
- ポケモン情報検索・復習リスト・履歴CSV。

## データと出典

- 280種類・すがた、合計467件の掲載文。うち今回追加は9件、引き継いだ既存データ458件は原文を変更していません。
- `NEW_VERIFIED_OFFICIAL_QUOTES.csv` に今回追加分の原文、掲載元URL、照合した掲載文章、掲載内容の適用範囲を記録しています。
- 新規文章は、ポケモン公式HP、旧作ゲーム公式HP、アニメ公式HPに実際に掲載された文章から抜き出したものであり、独自の要約文は登録していません。
- アニメやゲームの登場個体に限る特徴は、その出典と対象範囲を明記しています。
- 既存458件の全件について、このリリースで改めて外部サイト照合を行ったわけではありません。

## テスト

```
python self_check.py
python ui_smoke_test.py
```

- 5つの四択モード×2地方の問題生成、名前の伏字、文章選択肢の重複回避、データ形式をテスト。
- 回答後の「ここまでで終了」ボタンや情報画面は、Streamlitの模擬表示で検査。
- Streamlit自体の起動・実ブラウザの表示や実際の画像配信は、この環境からは未確認です。
